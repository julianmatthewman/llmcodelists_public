# llmcodelists_public

This repository contains evaluation scripts and codelists.

## Project Structure

- `embed_gemini.R`: Script for embedding using Google's Gemini API.
- `embed_gemini_read.R`: Script for embedding using Google's Gemini API (Read codes only).
- `embed_ollama.R`: Script for embedding using Ollama and MedCPT.
- `vitals.R`: Script performing the evaluations using the vitals framework.
- `eval.R`: Script to report the evaluations.
- [`codelists/`](codelists/) Reference codelists.
- [`claude_code_codelists/`](claude_code_codelists/): Codelists generated using Claude Code.
- [`docs/`](docs/) Evaluation bundles for hosting with GitHub pages.
